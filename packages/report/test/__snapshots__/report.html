What to fix first

  1. A form field has no label.

    • Critical
    • 2 problems
    • 1 page or file

    Who this affects: Screen reader users do not know what to type.

    How to fix it: Add a label tag that names the field and points to it.

    Standards and rule
    • WCAG 4.1.2 Name, Role, Value
    • Rule: axe-core 4.14.0, label

  2. Text does not stand out enough from its background.

    • Serious
    • 1 problem
    • 1 page or file

    Who this affects: People with low vision or color blindness may not be able to read it.

    How to fix it: Make the text darker or the background lighter. Aim for a contrast ratio of at least 4.5 to 1.

    Standards and rule
    • WCAG 1.4.3 Contrast (Minimum)
    • Rule: axe-core 4.14.0, color-contrast

  3. A link has no text.

    • Serious
    • 1 problem
    • 1 page or file

    Who this affects: Screen reader users hear link but not where it goes.

    How to fix it: Add link text, or add alt text to the image inside the link.

    Standards and rule
    • WCAG 2.4.4 Link Purpose (In Context)
    • WCAG 4.1.2 Name, Role, Value
    • Rule: axe-core 4.14.0, link-name

  4. An image has no alt text.

    • Serious
    • 1 problem
    • 1 page or file

    Who this affects: Screen reader users miss what the image shows.

    How to fix it: Add alt text to the image in Acrobat, or in the program you made the file with.

    Standards and rule
    • WCAG 1.1.1 Non-text Content
    • Rule: veraPDF 1.30.3, 7.3-1

  5. The PDF does not show a title in its window.

    • Serious
    • 1 problem
    • 1 page or file

    Who this affects: Screen reader users hear a file name that may not say what the file is.

    How to fix it: Add a title in the file properties and set the file to show it.

    Standards and rule
    • WCAG 2.4.2 Page Titled
    • Rule: Widedoor PDF checks 0.0.0, pdf-title-displayed

  6. An image has no text alternative.

    • Moderate
    • 1 item to check by hand
    • 1 page or file

    Who this affects: Screen reader users miss what the image shows.

    How to fix it: Add alt text that says what the image shows. Use empty alt text for images that are only for looks.

    Standards and rule
    • WCAG 1.1.1 Non-text Content
    • Rule: axe-core 4.14.0, image-alt

  7. A person needs to check that the tags read in the same order as the page.

    • Moderate
    • 1 item to check by hand
    • 1 page or file

    Who this affects: If the order is wrong, screen reader users hear the content mixed up.

    How to fix it: Check the reading order in Acrobat and fix any parts that are out of place.

    Standards and rule
    • WCAG 1.3.2 Meaningful Sequence
    • Rule: Widedoor PDF checks 0.0.0, pdf-reading-order
