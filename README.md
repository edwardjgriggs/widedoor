# Widedoor

Widedoor is an open source accessibility checker that lets a developer or a small business without an accessibility specialist test websites and PDFs against Section 508 and WCAG 2.1 AA. It produces a plain-language report of what is wrong, who it affects, and how to fix it, a guided manual review for the checks no tool can automate, and an Accessibility Conformance Report (ACR) in OpenACR and VPAT 2.5 format. It never claims conformance it did not test: unreviewed items read "Not Evaluated."

## Status

Pre-alpha. Nothing is released and the interfaces will change.
